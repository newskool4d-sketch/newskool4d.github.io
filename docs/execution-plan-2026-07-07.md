### 문서가 놓친 구조적 사실 2건

1. **git 저장소는 `incheon-edu-map`에만 있다.** 최상위·래퍼 폴더는 저장소 밖이다. 따라서 문서 P0-3이 제안한 "최상위 `package.json`에 `"type": "module"` 추가"는 로컬 경고만 없앨 뿐, 저장소를 clone한 환경(CI 포함)에서는 경고가 재발한다. → **앱 루트에 `package.json`을 신설**하는 것이 정본 해법 (CI 도입의 선행조건이기도 함).
2. **카카오 Web 도메인 미등록 리스크.** 배포 출처(`newskool4d-sketch.github.io`)가 카카오 개발자 콘솔 Web 플랫폼 도메인에 등록되어 있지 않으면 실 키를 넣어도 SDK 로드가 실패한다(과거 세션에서 확인된 이슈). 실 키 스모크(P0-5)의 선행조건인데 문서에 없다.
